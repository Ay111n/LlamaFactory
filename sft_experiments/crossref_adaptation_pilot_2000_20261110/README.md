# Matched bilingual and cross-reference SFT pilot

This pilot uses the frozen 2,000-pair subset prepared under finetuning, excluding the prior 200 diagnostic UIDs. Each arm has 4,000 training records with exactly the same order and response targets. The reference arm replaces 1,000 Tibetan prompts with the existing v2 English-reference wrapper. It adds no generated response or answer-label field.

The native LlamaFactory Qwen3 template runs with enable_thinking=false. Only the existing response and native termination tokens receive loss; the empty thought prefix is prompt-masked. All native target sequences must be identical between arms and untruncated before launch. Both arms start from the same supplied sft-new2 path, use rank-32 LoRA, learning rate 5e-5, effective batch 32, two epochs and seed 3407. Reference inputs cost additional prefill computation; this is a matched-supervision comparison, not equal FLOPs.

Run `pilot.py preflight --model /path/to/sft-new2` with the training environment. Then run `pilot.py launch --gpus 6 7`. Launch rechecks the data/cache/source hashes, empty output directories and idle selected GPUs. The supervisor records PIDs, exit codes, native trainer state and adapter hashes. The training worker passes a dictionary to native run_exp, avoiding this checkout's broken CLI JSON-file reader. The first failed CLI launch is retained in ignored runtime/. `pilot.py status` reads progress without starting work.

Training artifacts and resolved machine paths stay in ignored runtime_v2/, weights/checkpoints stay under finetuning/model/sft/. A completed training run is not an effectiveness result. Subsequent checks must use the held-out training-side diagnostic and Tibetan-only 666DEV; no TEST tuning or reference response supplied to the deployed student.

`after_training.py run` waits for both successful final adapters, performs CPU merges with the existing verified merger, then runs 40 reference-conditioned diagnostic generations and full 666DEV Tibetan-only OFF evaluation per arm. It uses at most two idle inference GPUs and preserves all outputs. Native DEV settings are 32768 context / 32000 output, temperature 0.6, top_p 0.95, top_k 20, seed 42. Diagnosis uses 8192 output tokens. The paired accuracy report is generated automatically; semantic review of the 40 diagnostic responses remains pending.
